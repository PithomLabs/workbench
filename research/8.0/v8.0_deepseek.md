# 0. Executive Thesis

The v7.x architecture was built around a **candidate structural layer** (Tate/adelic mathematics) applied to a BM baseline, with an F0–F11 gate system and a five-class bridge taxonomy. The architecture was disciplined, but it was **over-built**: it assumed the conclusion (arithmetic participates in physics) and then constructed machinery to test it.

v8.0 inverts the order. It starts from **BM alone**, identifies the exact-value gap (if any), and only then adds the **minimal arithmetic structure**. The program is:

$$
\boxed{
\text{BM IR baseline}
\;+\;
\text{AS candidate RG closure}
\;+\;
\text{candidate arithmetic constraint at the sharp corners}
}
$$

The central question is no longer "does Tate/adelic structure participate in physics?" It is:

$$
\boxed{
\text{Is there a BM-accessible observable with an exact value
not explained by calculus, algebra, or geometry alone?}
}
$$

If yes, and if the value lies in arithmetic's shine domain, then the minimal arithmetic structure is tested against a matched generic null. If the null survives, arithmetic is a spectator. If the null fails, arithmetic earns promotion to the next gate.

**The single decisive test** is frozen: interference phase in a two-slit setup, minimal \(\mathbb{Z}/p^L\mathbb{Z}\) arithmetic, matched generic phase null.

# 2. The Sharp-Corners Principle

Per the Reality-First discipline (see companion constitution), each mathematical structure has a **shine domain**, a **silence domain**, and a **partial domain**.

**Arithmetic's shine domain:**
- exact quantization (which integer, which fraction);
- consistency enforcement (anomaly cancellation);
- symmetry classification (which representations);
- cross-place consistency (local descriptions agreeing globally);
- spectral/statistical fingerprinting.

**Arithmetic's silence domain:**
- dynamics (calculus owns this);
- Born rule (the wall all maps share);
- gauge group / particle content (empirical);
- spacetime geometry (geometry owns this);
- prime selection (no mechanism found).

**The rule:**

$$
\boxed{
\text{Arithmetic is tested only where it shines.}
}
$$

Testing arithmetic outside its shine domain is a category error. A null result there is not evidence against arithmetic; it is evidence that the test was misplaced.

**The BM-accessible corners in arithmetic's shine domain are exactly four:**
1. interference phase (exact quantization);
2. arrival-time distribution (statistical fingerprinting);
3. Bell correlations (cross-place consistency);
4. energy-level statistics (spectral fingerprinting).

If none of these shows a null-separating arithmetic effect, the arithmetic branch retires.

$$
\boxed{
\text{one finite abelian group } \mathbb{Z}/p^L\mathbb{Z}

**Why this is minimal:**
- It is the smallest object where arithmetic structure (prime \(p\), level \(L\)) is present;

- It is already the frozen design in the minimal test record.

Everything else — adeles, zeta functions, Green functions, Tate curves, Langlands correspondences — is **downstream**. It is added only if the minimal structure fails and there is a specific reason to believe more structure helps.

# Article II — The Sharp-Corners Principle

Each mathematical structure has a **shine domain**, a **silence domain**, and a **partial domain**. The agent must not test a structure outside its shine domain.

**Arithmetic's shine domain:**
- exact quantization (which integer, which fraction);
- consistency enforcement (anomaly cancellation);
- symmetry classification (which representations);
- cross-place consistency (local descriptions agreeing globally);
- spectral/statistical fingerprinting.

**Arithmetic's silence domain:**
- dynamics (calculus owns this);
- Born rule (the wall all maps share);
- gauge group / particle content (empirical);
- spacetime geometry (geometry owns this);
- prime selection (no mechanism found).

**Rule:**

$$
\boxed{
\text{Arithmetic is tested only where it shines.}
}
$$

**Checklist — before any test:**

- [ ] Is the target observable in arithmetic's shine domain?
- [ ] If no, is the test misplaced?
- [ ] If yes, is the test targeting one of the four corners (interference phase, arrival-time distribution, Bell correlations, energy-level statistics)?

**A null result in a silence-domain test is not evidence against arithmetic.** It is evidence that the test was misplaced.
