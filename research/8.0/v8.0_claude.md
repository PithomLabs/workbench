# 0. Executive Thesis

A theory of everything does not need to be one substance with everything else built on top of it. It needs four things done honestly: an actual account of what exists (the dancer), an actual engine for how it changes (the dance), an actual account of the arena it changes in (the stage), and an honest map of which mathematical language is native to each of the first three — used as a census, not chosen as a foundation.

Nine-plus adversarial rounds, consolidated in the companion Reality-First survey, produced a specific, checkable answer to that fourth question. Of fifteen branches of mathematics tested against the actual content of physics, exactly one — calculus — is confirmed to *generate* anything. The rest, arithmetic included, are censuses: languages that describe what survives, what is classified, what is forbidden, what is conserved. None of them build the dance. This document takes that finding seriously as an organizing principle rather than a footnote.

$$
\boxed{
\text{BM (dancer + dance, via calculus)}
\;+\;
\text{AS (stage, via geometry + RG)}
\;+\;
\text{arithmetic held in reserve until its own confirmed role (invariant description) is actually needed}
}
$$

# 4. The Arithmetic Re-Entry Condition

The formal gate that replaces "let's not bolt Tate math in until necessary" with something checkable.

**Trigger.** Run BM+AS (§3) with zero arithmetic content assumed. If this construction produces an invariant — a spectrum, a partition function, a symmetry classification, a duality — inspect its values.

**Test, taken directly from the Reality-First survey's own dividing line:**

1. Is the invariant discrete because of topology (a winding number, a Chern class) or an ordinary symmetry group (SU(2) angular-momentum quantization)? → **Stays with topology or symmetry. Arithmetic does not re-enter.**
2. Is the invariant a generic, continuously-varying real number? → **Arithmetic is inapplicable. Full stop.**
3. Does stating the invariant's value precisely require an algebraic number field, a modular form, a Galois action, or an L-function? → **Only here does Appendix R open — and only the specific reserve item matching that invariant's structure, not the whole apparatus at once.**

**Worked calibration, so the test isn't abstract:** a Chern number is integer-valued and fails the test (topology owns it). A fractional quantum Hall filling fraction is rational-valued and, per the survey's own strongest confirmed case, is *algebraic and exact* in a way ordinary topology alone does not force — this is close to the one historically-confirmed case where the test would have passed. A generic scattering cross-section is continuous and fails outright.

**Status:** OPEN. BM+AS have not yet been run far enough to know whether they produce a Level-2-or-higher invariant. This is now the actual research target, not an assumption to build around.
