# 6. The Five Mediating Objects (Where Arithmetic Connects to Continuum)

Based on the Reality-First audit, arithmetic connects to continuum physics
through exactly five types of mediating objects. These are the only known
channels; any other proposed connection is speculative.

## MO-1 — Spectrum
The eigenvalues of a quantum Hamiltonian coincide with arithmetic data.
- Example: Berry–Keating conjecture (H = xp; eigenvalues = Riemann zeros)
- Status: CONJECTURAL

## MO-2 — Partition function
The partition function of a physical system is a number-theoretic object
(modular form, L-function, or related).
- Example: Ising model at criticality (partition function = modular form)
- Status: VERIFIED for integrable models; open for non-integrable

## MO-3 — Trace formula
The spectrum of the Laplacian on a geometric space is computable from
arithmetic data via a trace formula.
- Example: Selberg trace formula on arithmetic hyperbolic surfaces
- Status: MATHEMATICAL THEOREM; not experimentally realized

## MO-4 — Modular symmetry
The physical theory has a discrete symmetry under SL(2,ℤ) or a subgroup,
constraining the spectrum.
- Example: 2D CFT partition functions; string compactifications
- Status: VERIFIED (theorem); physical consequence well-established

## MO-5 — L-function
A physical observable has a generating function that is an L-function.
- Example: Freund–Witten adelic string amplitudes
- Status: FORMAL/TOY; untested

**Key pattern:** all five connect arithmetic to continuum at the
*spectral/statistical/symmetry* level, never at the *dynamical* level.
Dynamics is not where the connection occurs.

## §4 — THE OWNERSHIP CRITERION

**The single most important tool in the program.**

Before claiming that arithmetic structure is *physically causal*, run:

- If NO: the arithmetic is SPECTATOR. File and move on.

**Step 4 — Classify (if causal).**

- ARITHMETIC-CONSTRAINED: arithmetic restricts the admissible form.
- HYBRID: both arithmetic AND an independent sector are necessary.

**Step 5 — Record.**
CLAIM_ID, ingredient, null used, result, classification, debt, date.

## §6 — THE PRE-REGISTRATION CHECKLIST

Before any computation, experiment, or data analysis:

- [ ] **Prediction frozen:** the expected result is written down in

- [ ] **Null model frozen:** the comparison null is specified and its

- [ ] **Kill condition frozen:** the condition under which the hypothesis
      is abandoned is written down and signed
- [ ] **Analysis pipeline frozen:** the code/method for evaluating the
      result is written and committed
- [ ] **Conflicts declared:** any known confounds, systematic errors,
      or alternative explanations are listed
- [ ] **Trials correction:** if multiple comparisons are made, the
      correction factor is pre-specified

**Violating any item invalidates the test.**
