A few things worth flagging before this becomes the settled record of where things stand, because a couple of items have drifted in the retelling, and one new claim (Item 13) needs the same scrutiny everything else in this program has gotten.

**Item 13 — "action cellulation" needs the same treatment as every other candidate mechanism, and right now it's getting a pass it hasn't earned.** This document is admirably disciplined about tagging speculative content everywhere else — "candidate axiom/hypothesis, not result of IST" is exactly the right label. But notice what's missing: no structural detail on *how* dyadic cell structure would upgrade to carry a universal action scale, no check against the constraints already established earlier in this same investigation. Specifically: does action cellulation produce a *topological* quantization (circulation around loops in configuration space, à la Wallstrom, tied to $I_U$'s actual geometry) or does it produce a *combinatorial* one (a fixed spacing between discrete cells)? Those are different mechanisms with different failure modes. A combinatorial cell-spacing story would need to explain the mass-independence problem flagged repeatedly (T4, the two-mass test) — a fixed cell size doesn't obviously scale as $1/m$ the way the Fisher coefficient must. If "action cellulation" hasn't been checked against T4 yet, it should be, before it graduates from a name to a candidate — right now it's a placeholder with a good label, not yet a mechanism.
